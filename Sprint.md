# Planejamento das Sprints - Cachoeira Tracker

Este documento organiza as tarefas do projeto em Sprints semanais, com base na prioridade definida no backlog.

---

## Sprint 1 - Estrutura e Acesso ao Sistema

Objetivo: Implementar as funcionalidades essenciais de acesso e base do sistema (MVP).

| ID | Tarefa                   | Descrição                                 |
| :- | :----------------------- | :---------------------------------------- |
| 02 | Cadastro de Usuário      | Criar formulário com Nome, E-mail e Senha |
| 03 | Login/Autenticação       | Implementar autenticação com Firebase     |
| 01 | Tela de Splash           | Criar tela inicial do aplicativo          |
| 05 | Perfil do Usuário        | Estrutura inicial do perfil               |
| 04 | Recuperação de Senha     | Implementar fluxo de recuperação          |
| -  | Estrutura do Projeto     | Organização de pastas e arquivos          |
| -  | Configuração do Ambiente | Configuração do Node.js e dependências    |

Entregas:

* Sistema de autenticação definido
* Estrutura inicial do projeto criada
* Base do sistema funcional

---

## Sprint 2 - Registro de Atividades

Objetivo: Permitir que o usuário registre visitas e acompanhe seus dados.

| ID | Tarefa               | Descrição                      |
| :- | :------------------- | :----------------------------- |
| 07 | Iniciar Atividade    | Iniciar rastreamento da trilha |
| 08 | Cronômetro           | Registrar tempo da atividade   |
| 09 | Cálculo de Distância | Medir distância percorrida     |
| 11 | Finalizar Visita     | Encerrar atividade             |
| 12 | Resumo da Visita     | Exibir dados finais            |
| 10 | Nível de Intensidade | Classificar dificuldade        |

Entregas:

* Sistema de registro de atividades estruturado
* Dados principais definidos e organizados
